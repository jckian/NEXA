# 模組化平台組合規則 (Frame / Infill System)

## 1. 基準模組
- 立體網格模組 **M = 259**(259 × 259 × 259 立方格)
- 構材斷面 t = 10 → 淨開口 C = M − 2t = **239**
- 雙跨 = 2M = 518
- 半跨板寬 = 121(2 片/跨)
- 帷幕板 = M − 10 = 249(含 10 板縫),厚 19
- 半層錯層偏移 = M/2 ≈ 129

## 2. Block 元件庫

|---|---|---|
| PLATE | 259×269×5 | 基礎底板,每柱格一片 |

## 3. 定位規則(以平台原點 O = (Ox, Oy, Oz) 為基準)
1. **柱格線**:Xi = Ox + i·M,Yj = Oy + j·M
2. **PLATE**:z = Oz + 3(頂面 = Oz + 8)
3. **框架**:第 k 層基準 zk = Oz + 8 + k·M(k = 0,1,2…)
4. **樓板**:主層 deck 底 = zk + 5;錯層 deck = 主層 + M/2
5. **窗**:窗頂 = zk + 243(即下一層框架底 − 16);一跨 = window(173) + window-1(66),玻璃面貼外緣網格線
6. **帷幕**:面外偏移 19,垂直間距 250,由頂往下排,可越過 z = Oz
7. **STR**:插入位置 zk + 28,佔一跨一層

## 4. 組裝順序
PLATE → VERTICALFRAME / 1_@ 01(垂直堆疊)→ FRAME-HORIZONTAL(層界)→ module-deck / deck-1 → window + window-1 → FACADE_PANE07 → STR

## 5. Infill 填充律(淨開口 239 的合法分割)
- 樓板:121 + 121(標準)或 173 + 66 走道
- 立面:173 + 66(一大一小窗)或整跨帷幕
