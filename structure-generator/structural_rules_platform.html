A How it adapts to any shape

The engine never assumes a footprint. It inside-tests sample points against the real massing to build a per-floor occupancy grid. Every system below is derived from that grid and from how it changes floor to floor — so an L-shape, a tower, a stepped podium, or a single solid all generate correctly without changing the code.

Read massing

Gather selected meshes (or a whole collection). Build one BVH and an even-odd ray test for "is this point inside the volume?".

Detect floors

By level tags (_L0…_Ln / _B1) when present, otherwise slice the height at the floor-to-floor value. Each floor gets an occupancy grid + program tags.

Zones & transfers

Compare occupancy between floors: cells lost upward = exposed roof; cells gained = cantilever needing support below = transfer level.derived, not hardcoded

Adaptive grid

One global column grid (spacing from program bays) clipped to each floor's occupancy, so columns stack and alignment is maximised.

Core + shafts

Detect circulation objects and wrap them in shear walls to foundation & roof; if none, place a central core sized to the smallest upper floor.

Columns → foundation

A column is grounded only if its grid point is occupied continuously down to the base. Otherwise it transfers — a girder ties it to the nearest grounded line.

Beams + slabs

Beams connect adjacent occupied grid points on both axes; slabs are voxel plates following the occupancy, so atrium voids stay open.

Mass-top roofs

Every terminated block is capped, and its columns/beams extend up to that roof for a complete load path.

Curtain wall + fins

Boundary cells become the facade; fins sit on a mullion grid and merge into continuous runs per plane (deeper on column lines).

Underground

Diaphragm wall around the lowest floor (grade → toe) and a grade-beam frame tying every foundation column and core.

Validate

Checks every column reaches foundation/transfer and no beam is single-ended; writes a report. PASS / CHECK
